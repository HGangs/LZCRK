# AGENT.md · 需求文档（PRD）

> 项目：出入库存管理工作台（单文件 `index.html` + Electron 桌面壳）
> 本文件记录产品需求与验收标准，不记录实现细节（实现见 `state.md` / `时间线.md`）。

## 一、产品定位

面向工程施工单位的物资出入库管理工作台：仓库入库 → 项目领用出库 → 项目持有与结存，支持多项目、多仓库、角色权限、备份恢复。

### 阻塞（需用户操作）
1. **CloudBase 原生域名需备案**：`*.tcloudbaseapp.com` 与 `*.webapps.tcloudbase.com` 访问 HTML 会强制弹「风险提醒」并限访问量，无法正式使用 → 已改用 WorkBuddy 托管域名；如需自有域名，需提供已备案域名并绑定。
2. ~~GitHub 连接器只读~~ **已绕过**：连接器的 GitHub App 只授予读权限，用户端无权限可改（`/settings/installations` 只能选仓库范围）。改用 SSH 部署密钥直推：`~/.ssh/id_wms` + `config` 指向 `ssh.github.com:443`；git 需 `http.sslBackend=openssl`（schannel 吊销检查会失败）。
3. **云端数据为空**：`public.wms_state` 0 行，需在页面导入真实数据后才会产生首次写入。

### 安全边界
- 当前匿名登录 + RLS 允许所有登录者读写同一文档 → 拿到链接即可改动数据。
- 升级路径：开启邮箱/用户名密码登录，并把写策略收紧到指定 uid 或角色。

## 三、历史需求（v4.18）

### 需求 1：入库台账 / 出库台账支持导出

- 入库台账、出库台账页面均提供「导出」按钮。
- 导出内容为当前筛选条件下的单据明细（单号、日期、类型、仓库、项目、物料、规格、单位、数量、经办人、备注等）。
- 无数据时按钮禁用或提示；导出需权限校验（`export`）。

### 需求 2：出库登记新增「领用施工单位」+ 施工单位管理模块

- **出库登记**：新增「领用施工单位」字段（下拉选择，数据来自施工单位档案），可为空（历史单据不受影响）。
- **基础档案 → 施工单位管理**（新页面）：
  - 列表展示：单位名称、联系人数量、关联项目数、备注。
  - 新增 / 编辑 / 删除。
  - 每个单位可维护**多个联系人**，每个联系人含**姓名**和**电话**（可增删行）。
  - 删除单位时不得删除历史数据：仅解除引用（出库流水、项目上的 `unitId` 置空）。

### 需求 3：项目信息新增「施工单位」+ 项目列表筛选

- 项目档案新增「施工单位」字段（下拉选择）。
- 表单位置：**在「负责人」列之前**。
- 项目列表（项目清单）上方新增「施工单位」筛选框；与现有搜索、行政区、负责人、状态筛选可叠加。
- 项目详情、项目表单同步展示与编辑该字段。

### 需求 4：设备使用看板（新页面）

#### 4.1 单位卡片（每个施工单位一张）

- 单位名称、联系人摘要。
- **累计领用物料次数**：该单位名下出库单数（按单据号去重）。
- **各物料领用数量**：该单位出库流水按物料汇总。
- **扣减该单位负责园所设备用量后的各物料剩余数量**：该单位领用量 − 该单位负责项目的项目持有量（按物料）。

#### 4.2 顶部总统计卡片

按物料汇总：

| 指标 | 口径 |
|---|---|
| 入库总数 | 该物料全部入库流水数量合计 |
| 出库总数 | 该物料全部出库流水数量合计 |
| 剩余总数 | 仓库现有库存（期初 + 入库 − 出库） |
| 项目使用数量 | 项目持有量合计（出库 − 退回） |
| 出库与使用数量差异 | 出库总数 − 项目使用数量（预警未落地/在途） |

## 三、硬性约束

1. **保留现有数据**：不修改、不迁移、不删除任何历史数据；新字段一律可选，缺失时按空处理。
2. **原有功能不回退**：既有页面、权限、备份、时钟、调拨等功能保持可用；全量测试须通过。
3. 权限三层（导航 / 按钮 / 事件层 `can(mod,act)`）必须覆盖新页面与新写操作。
4. 新页面注册需同步三处：`PAGES` + `MODULES` + `NAV_ORDER`（含 `renderNav` 过滤、`render` 兜底、`click` 的 nav 分支）。
5. 内置角色需补齐新模块权限；老角色走一次性迁移（`settings.permMig`），不改变其原有可见范围。

## 四、验收标准

- [ ] 入库台账 / 出库台账可导出，导出文件能正常打开且列齐全。
- [ ] 出库登记可选施工单位，保存后流水带 `unitId`。
- [ ] 施工单位管理可增删改，支持多个联系人（姓名 + 电话）。
- [ ] 项目表单施工单位在负责人之前；可保存、可筛选。
- [ ] 设备使用看板单位卡片与总统计数值与底层流水一致（用脚本核对）。
- [ ] 历史数据加载后数量不变（项目 / 物料 / 流水条数一致）。
- [ ] `node tests/run-all.js` 全绿。
